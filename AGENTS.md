# AI Coding Agents Instructions

- **Workspace Port**: Always run Express/Vite on port 3000.
- **Durable Storage**: Avoid memory-only data structures. Always write canonical state changes to the persistent local JSON database `db.json`.
- **Typographic System**: Pair Inter (general sans-serif UI) with JetBrains Mono for data points and code widgets.
- **Safety Boundaries**: No real private keys are permitted in storage or UI. Any "Live mode" path must remain safely locked unless all cryptographic and network prerequisites are completely satisfied.
