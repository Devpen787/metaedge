# MetaEdge: Agentic Trading Platform

MetaEdge is an advanced, AI-powered trading interface designed for managing autonomous trading agents, monitoring real-time token performance, participating in prediction markets, and executing live on-chain operations.

## Features

- **Agent Workshop**: Deploy, configure, and manage intelligent AI trading agents. Set custom rules, risk tolerance, and asset pairs for autonomous market execution.
- **Agent Arena**: A competitive testing ground for agents. Test your strategies risk-free, enter trading leagues, and climb global leaderboards.
- **Swarm Copilot**: An intelligent AI assistant. Use natural language to query market insights, analyze tokens, and understand complex DeFi mechanics.
- **Intent Solver**: A high-level text-to-strategy execution engine. Type your intent (e.g., "Deploy an arb bot on ETH/USDC with $5k") and watch the AI compile it into actionable parameters.
- **Platform Analytics**: Global data dashboard tracking user adoption, simulated volumes, agent deployments, and real-time platform events.
- **Command Palette (Cmd+K)**: Seamless global navigation and search overlay to switch contexts quickly.
- **MetaMask Agent Wallet Integration**: Full support for real on-chain interactions via the `@metamask/agentic-cli`. Authenticate with your wallet, check real-time Base network balances, and execute on-chain token transfers securely from within the MetaEdge interface.
- **Trading Hub**: A high-performance dashboard with live, simulated market charting, integrated trading volume metrics, and order execution for top assets (BTC, ETH, SOL, LINK, DOGE, etc.).
- **Prediction Markets**: Engage in decentralized speculation and forecasting with real-time odds, liquidity metrics, and custom market creation.
- **Paper vs. Live Mode**: Seamlessly switch between zero-risk paper trading simulations and live on-chain deployments via your Agent Wallet.
- **Specs Catalog**: Track requirements for running edge node infrastructure to support the MetaEdge autonomous ecosystem.

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide React (Icons), Motion (Animations).
- **Backend**: Node.js, Express.js.
- **Persistence**: Lightweight Local JSON storage (`db.json`) for configuration and agent state.
- **Web3 Integration**: `@metamask/agentic-cli` for server-side wallet management and Base network transactions.

## Setup & Installation

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn
- MetaMask Agent Wallet Early Access (for generating a CLI token)

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Configuration
Copy the sample environment file to create your local `.env`:
```bash
cp .env.example .env
```
Ensure you have the appropriate keys set in the `.env` file (such as your Gemini API Key if testing agent intelligence).

### 3. Local Development
Run the development server. This boots up both the Express backend and the Vite React frontend on port `3000`.
```bash
npm run dev
```

### 4. Production Build
To create an optimized production build and bundle the Express server:
```bash
npm run build
npm run start
```

## Running Live On-Chain Transactions (MetaMask Agent Wallet)
1. Initialize the MetaMask Agent CLI on your local machine using `npx @metamask/agentic-cli@3 login browser --no-wait`.
2. Grab the `cliToken:cliRefreshToken` generated by the authorization step.
3. Open the MetaEdge application, click the **Wallet** button in the top navigation bar.
4. Paste your CLI token to authenticate.
5. MetaEdge will securely orchestrate balances and transfers on the Base network (Chain ID 8453) via the CLI background processes.

## Extensibility
To replicate or move this codebase:
- Copy the entire directory.
- `package.json` contains all dependencies necessary to run both the frontend and backend.
- Ensure the Node execution environment has access to bash/shell to execute the MetaMask agentic CLI via `npx` (as implemented in `server.ts`).
