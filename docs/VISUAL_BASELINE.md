# Visual Baseline

The current UI, naming, tone, tabs, and visual system are the product baseline. Do not simplify or replace them without explicit approval.

The application features a dark, cyber/sovereign visual identity using generous negative space, `Inter` for general typography, and `JetBrains Mono` for code and data. It uses custom SVG elements and specific color palettes that should be preserved.

Do not remove product personality. Do not convert this into a generic dashboard. Do not rewrite the frontend unless needed for modularity. Preserve what makes it feel premium.
